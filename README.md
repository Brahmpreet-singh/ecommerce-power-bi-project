# Madhav Ecommerce Sales Dashboard 📊

## 📌 Project Overview

This project is an **E-commerce Sales Dashboard built using Microsoft Power BI**. The dashboard analyzes sales and business performance through interactive visualizations and key performance indicators (KPIs).

The project focuses on understanding **sales, profit, quantity sold, customer performance, product categories, payment methods, monthly trends, and state-wise performance**.

## 📊 Key KPIs

* **Total Sales:** ₹438K
* **Total Profit:** ₹37K
* **Total Quantity Sold:** 5,615
* **AOV:** ₹121K

## 🔍 Dashboard Analysis

The dashboard provides insights into:

* 📈 Monthly Profit Trends
* 🛍️ Sales by Product Category
* 📦 Profit by Sub-Category
* 💳 Sales by Payment Mode
* 🗺️ State-wise Profit Analysis
* 👥 Customer-wise Sales Analysis
* 📊 Quantity Distribution by Category

Clothing contributes the highest share of quantity at **63%**, followed by Electronics and Furniture. **UPI** is the leading payment mode with **44%** of transactions.

## 🎯 Project Objective

The objective of this project is to transform raw e-commerce data into an **interactive business intelligence dashboard** that helps identify sales trends, profitable products, customer behavior, and overall business performance.

## 📷 Dashboard

The Power BI dashboard contains interactive charts, filters, KPI cards, and visualizations for exploring different aspects of the e-commerce dataset.
